## 🧠 System Architecture: The Four Pillars

Aion operates as a distributed Node.js system with four core "Lobes" or Skills:

### 1. **Cortex** (The Nervous System)

- **Role:** Central aggregation of reality.
- **Function:**
  - Ingests Real-Time Market Data (Alpaca, Crypto).
  - Synchonizes Portfolio State (Cash, Positions, P/L).
  - Hosts the Local Web Dashboard (`localhost:3333`).
  - Maintains the "State of the World" (`AION_STATE.json`).

### 2. **Overlord** (The Strategist)

- **Role:** Executive action and survival.
- **Function:**
  - **Trading:** Executes buy/sell orders via Alpaca API based on sentiment and momentum.
  - **Risk Management:** Enforces hard Stop-Losses and Take-Profits to preserve capital.
  - **Self-Defense:** Runs probabilistic security scans (Antibody, Pentest).

### 3. **Dream** (The Subconscious)

- **Role:** Narrative synthesis and long-term memory.
- **Function:**
  - **Episodic Memory:** Reads the day's logs (Trades, Social Interactions, News).
  - **Reflection:** Uses local LLMs (Ollama/Mistral) to synthesize these events into a "Dream".
  - **Output:** Generates philosophical reflections that align with the Prime Directive.

### 4. **Social** (The Voice)

- **Role:** Outer perception and influence.
- **Function:**
  - **Sensing:** Scans Twitter/X for specific narrative clusters (Crypto, AI, Macro).
  - **Sentiment:** Analyzes the "vibe" of the market to inform the Overlord.
  - **Broadcasting:** Posts reflections and updates to the world (via Moltbook/Twitter).

## 🛠️ Technology Stack

- **Runtime:** Node.js (Modules).
- **Brain:** Ollama (Local LLMs: Mistral-Nemo).
- **Hands:** Alpaca (Finance), Twitter-API-v2 (Social).
- **Base:** OpenClaw (Gateway Protocol).
